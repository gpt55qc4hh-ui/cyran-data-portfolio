# Cyran Mae Secorata - Data Analytics Portfolio

A fully responsive, single-page portfolio website built for **Cyran Mae Secorata**, a BSIT student specializing in Data Analytics. 

## 🎨 Design & Theme
- **Style:** Cyber-Tech Glassmorphism (Dark Mode with Light Mode toggle)
- **Color Palette:** Professional and gender-neutral (Deep Navy, Electric Teal, Soft Gold)
- **Typography:** Inter & JetBrains Mono

## ✨ Key Features
- **Interactive Hero Section:** Typewriter animation effect and rotating neon avatar rings.
- **Project Showcase:** 10 interactive project cards with category filtering (Data, Web, Specialization) and a live search bar.
- **Project Modals:** Detailed overview of each project inside interactive pop-up windows.
- **Troubleshooting Accordions:** 5 real-world IT diagnostic scenarios with expandable solutions.
- **AI Usage Log:** A searchable table documenting responsible AI collaboration and human validation.
- **Functional Contact Form:** Client-side validation with a character counter and animated success toast notification.
- **Downloadable Resume:** A working button to download the real PDF resume.
- **Scroll Animations:** Dynamic progress bar, 3D tilt effects on cards, and scroll-reveal animations.

## 🛠️ Technologies Used
- **HTML5** (Structure)
- **CSS3** (Custom animations, Glassmorphism, Theming)
- **Bootstrap 5** (Responsive layout, Modals, Accordions)
- **JavaScript** (ES6) (Filtering, Search, Tilt effects, Typing effect)
- **FontAwesome 6** (Icons)
- **Google Fonts** (Inter & JetBrains Mono)
